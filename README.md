# Пульт Яндекс Станции для iOS 9 (iPad)

Это тот же интерфейс, что и в Android-версии: часы, погода, «сейчас играет»,
обложка, прогресс, play/pause, переключение треков, громкость, настройки
(токен, выбор колонки, IP вручную, город, стиль/размер/положение часов).

Собрать IPA можно **без Mac** — через бесплатный macOS-раннер GitHub Actions.

## 1. Загрузить проект на GitHub

1. Создайте новый **приватный** репозиторий (например, `station-remote-ios`).
2. Распакуйте этот архив и загрузите **содержимое** папки в корень репозитория
   (должны оказаться `project.yml`, `Sources/`, `Resources/`, `.github/`).
   Через веб: *Add file → Upload files*, перетащите всё содержимое.

## 2. Собрать IPA

1. В репозитории откройте вкладку **Actions**.
2. Слева выберите **ios-ipa** → **Run workflow** → **Run workflow**.
3. Дождитесь зелёной галочки (5–8 минут).
4. Откройте завершившийся запуск, внизу скачайте артефакт
   **StationRemote-ios9** — внутри `StationRemote.ipa` (неподписанный).

## 3. Установить на iPad (Windows)

Неподписанный IPA нельзя поставить напрямую. Подпишите его своим Apple ID:

1. Установите [Sideloadly](https://sideloadly.io/) на Windows.
2. Подключите iPad кабелем, выберите `StationRemote.ipa`,
   введите Apple ID (бесплатного достаточно).
3. Нажмите Start; на iPad подтвердите установку.
4. На iPad: **Настройки → Основные → Профили и управление устройством** →
   ваше имя → **Доверять**.
5. Запустите приложение с домашнего экрана.

Бесплатный Apple ID даёт подпись на **7 дней** — потом повторите подпись
(данные приложения сохраняются).

Альтернатива: джейлбрейк + AppSync Unified — тогда подпись не нужна.

## 4. Настройка

1. Шестерёнка → вставьте OAuth-токен Яндекса (как в Android-версии:
   «Открыть страницу Яндекса» → скопировать `access_token` из адресной строки).
2. «Обновить список» → выберите **Яндекс Станцию**.
3. Если IP не определился: «IP вручную» → `192.168.1.5` → сохранить.
4. Город для погоды и стиль часов — там же.

## Ограничения iOS-версии

- **Голос** (микрофон/«Алиса») не поддерживается: на iOS 9 нет офлайн-распознавания,
  кнопка микрофона ничего не делает.
- **Звук на планшете** не поддерживается: воспроизведение остаётся на Станции
  (кнопка маршрута игнорируется).
- Остальное — подключение, состояние, обложка, прогресс, play/pause, треки,
  громкость, погода, часы, настройки — работает через тот же протокол glagol.

## Если сборка упала

Пришлите лог из Actions: чаще всего это выбор Xcode (armv7/ios 9) —
workflow сам берёт Xcode 13.x/12.x, но на некоторых образах он отсутствует.
Тогда замените `runs-on: macos-12` на `macos-11` и повторите.
